# SkillHub - منصة إدارة الدورات التدريبية

## اسم المشروع

**SkillHub**

## وصف المشروع

منصة إلكترونية لإدارة الدورات التدريبية تتيح للطلاب تصفح الدورات والتسجيل بها، ولإدارة المركز التحكم الكامل بالدورات والمدربين والتصنيفات.

## فكرة المشروع

توفير نظام متكامل يربط الطلاب بالمدربين عبر دورات مصنفة، مع لوحة تحكم شاملة للمسؤول ونظام تسجيل وصلاحيات آمن.

## المميزات

- تسجيل الدخول وتسجيل الخروج (Authentication) مع جلسات آمنة.
- نظام صلاحيات مزدوج: `admin` لإدارة المنصة و `student` للطلاب.
- CRUD كامل للتصنيفات (إضافة / عرض / تعديل / حذف).
- CRUD كامل للمدربين (إضافة / عرض / تعديل / حذف).
- CRUD كامل للدورات (إضافة / عرض / تعديل / حذف) مع ربطها بالتصنيفات والمدربين.
- رفع صور وعرضها للدورات والمدربين والتصنيفات.
- تصفح الدورات مع صفحة تفاصيل لكل دورة.
- التسجيل في الدورات من قبل الطلاب مع صفحة تعرض دوراتي المسجلة.
- نموذج "تواصل معنا" لاستقبال رسائل الزوار وعرضها في لوحة المسؤول.
- لوحة تحكم للمسؤول تعرض إحصائيات المنصة (الدورات، المدربين، التصنيفات، الطلاب، الرسائل).

## طريقة التشغيل

تنفيذ الخطوات بالترتيب التالي:

```bash
# 1) تثبيت الحزم الخاصة بـ PHP
composer install

# 2) تثبيت الحزم الخاصة بـ JavaScript
npm install

# 3) إنشاء ملف البيئة .env
cp .env.example .env

# 4) توليد مفتاح التشفير الخاص بالتطبيق
php artisan key:generate

# 5) إعداد اتصال قاعدة البيانات داخل ملف .env
# DB_CONNECTION=mysql
# DB_HOST=127.0.0.1
# DB_PORT=3306
# DB_DATABASE=training_center
# DB_USERNAME=root
# DB_PASSWORD=

# 6) إنشاء الجداول وتعبئة البيانات التجريبية (Seed)
php artisan migrate --seed

# 7) بناء ملفات الواجهة (CSS / JS)
npm run build

# 8) تشغيل الخادم المحلي
php artisan serve
```

ثم افتح المتصفح على الرابط: <http://localhost:8000>

### استيراد قاعدة البيانات (اختياري)

يتوفر ملف تصدير كامل لقاعدة البيانات (البنية + البيانات) داخل مجلد المشروع:

```
database/sql/training_center.sql
```

يمكن استيراده مباشرة بدلاً من خطوة الـ migrate and seed:

```bash
mysql -u root training_center < database/sql/training_center.sql
```
